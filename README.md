# Multi-camera 安防监控多目标检测与分析系统

## 项目简介
本项目聚焦于面向安防监控场景的多目标检测与分析，是计算机视觉与人工智能技术在公共安全领域的核心应用。系统集成了视觉大模型与规则库，实现了对人、物、环境的异常监控与预警，并支持云-边-端架构的实际部署。

## 主要功能
1. **视觉大模型集成**：支持主流视觉大模型的推理与调用，具备多目标检测、识别与分析能力。
2. **规则库制定与管理**：内置丰富的安防场景规则库，支持规则的自定义、扩展与案例管理。
3. **模型与规则融合决策**：实现大模型推理结果与规则库的融合，支持复杂场景下的智能决策与异常预警。
4. **云-边-端架构支持**：系统架构支持云端、边缘端与终端的协同部署，适应多种实际安防场景。

## 目录结构
- `app/`：主程序、API、核心逻辑、服务与工具模块
- `models/`：视觉大模型与推理相关模块
- `kb/`：规则库、案例库与知识管理
- `alarms/`：报警相关逻辑
- `bge-small-zh-v1.5/`：集成的视觉大模型文件
- `faces/`：人脸白名单等数据
- `static/`、`templates/`：前端静态资源与页面模板
- `logs/`、`sounds/`：日志与音频资源
- `test_*.py`：各类测试脚本
- `requirements.txt`：依赖包列表
- `run.py`：主运行入口

## 快速开始
1. **环境准备**
   - 推荐使用 Conda 环境，建议环境名：`vision_describe`
   - 安装依赖：
     ```bash
     conda activate vision_describe
     pip install -r requirements.txt
     ```
2. **模型准备**
   - 确保 `bge-small-zh-v1.5/` 目录下模型文件齐全
3. **运行主程序**
   ```bash
   python run.py
   ```
4. **测试与验证**
   - 可运行 `test_*.py` 文件进行功能测试

## 主要模块说明
- **app/**
  - `main.py`：主程序入口
  - `api/`：API 路由与 WebSocket 支持
  - `core/`：配置、日志、状态管理等
  - `services/`：摄像头、推理、流媒体、报警等服务
  - `utils/`：各类工具函数与第三方接口
- **models/**
  - `reasoning.py`、`ollama_reasoning.py`：大模型推理与融合
  - `vision.py`、`ollama_vision.py`：视觉模型相关
- **kb/**
  - `base.py`、`rule_source.py`：规则库与知识管理
  - `cases/`：典型案例数据
